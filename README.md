# Study Buddy 📚

Study Buddy is a beginner-friendly Flutter application created as a
Flutter Track 1 learning project.

The application helps students keep track of simple study tasks and
see their progress.

## Features

- 📚 View study tasks
- ✅ Mark tasks as complete
- ➕ Add new study tasks
- 📊 View study progress
- 🎨 Simple Material 3 interface
- 🧪 Flutter widget tests

## Getting started

Clone the project and move into the project folder:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd study_buddy
```

Get the Flutter packages:

```bash
flutter pub get
```

Run the tests:

```bash
flutter test
```

Run the application:

```bash
flutter run
```

## Testing

The project includes widget tests that check:

* The main Study Buddy screen loads correctly.
* A user can add a study task.
* A user can interact with a study task.

Run all tests with:

```bash
flutter test
```
