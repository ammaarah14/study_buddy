# Study Buddy - Flutter Track 1 Project

A beginner-friendly Flutter/Dart project demonstrating:
- Dart variables, lists, maps, functions and classes
- Flutter MaterialApp and Scaffold
- StatelessWidget and StatefulWidget
- Layout with Column, Row, Card and ListView
- Buttons and user interaction
- State updates with setState
- Basic navigation
- Simple form-style input

## Run

```bash
flutter pub get
flutter run -d chrome
```
